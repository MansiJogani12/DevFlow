# DevFlow

DevFlow is a Jira-style project management app built with Next.js.

## Getting Started

Install dependencies and run the app locally:

```bash
npm install
npm run dev
```

## Environment

Set your Supabase values in `.env` before starting the app:

- `DATABASE_URL`
- `DIRECT_URL`
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

## Notes

This project uses Prisma and Supabase for data access and persistence.
